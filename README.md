# Angelo Mall Go

Standalone chat-first shopping and local-delivery PWA concept for Angelo Mall, Nigel, Gauteng, South Africa.

This repository is being populated from the preserved Phase 1 prototype in `ShireElf123/Student-portal-2`, branch `arena/c2912789-student-portal-2`, directory `angelo-mall-go/`. The original source PR remains open and unmerged as a recovery copy.

Demo only: no real tenant partnerships, accounts, payments, messaging, or delivery dispatch are active.
